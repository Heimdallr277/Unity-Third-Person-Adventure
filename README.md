# Unity Third-Person Adventure

A 3D third-person adventure game prototype developed in Unity and C# as a four-person team project.

The game features exploration, platforming, environmental puzzles, interactive objects, and basic combat mechanics across three designed levels.

## Features

- Third-person character movement and exploration
- Interactive environments and puzzle mechanics
- Collectibles, inventory, and key-based progression
- Environmental hazards and respawn mechanics
- Health, inventory, and objective UI
- Multi-level gameplay and enemy encounters
